#  Module 401 Lab 2.1 Interactive Accessibility Lesson

## Reflection Questions

### 1. What accessibility enhancements were the most challenging to implement, and why?
The hardest part for me was the tags for the inputs. I feel it's not intuitive at all to combine the class name and the input type. Plus, it gets super confusing that the label does close with a slash (`</label>`), but the input doesn't close the same way with another input tag, so that becomes a real mess for me.

### 2. How do ARIA attributes improve the experience for users relying on assistive technologies?
They improve the experience by making the page more user-friendly for people who need some kind of visual or auditory assistance. Things like `aria-polite` are used for this, although the truth is that wasn't really explained well in the Scrimba course and I had a hard time understanding it.

### 3. What tools did you use to check color contrast, and how did they help?
The tool I used to check contrast was the pseudo-element next to the `contact-input` tag, which helped me properly adjust the colors and the text inside the little boxes.
